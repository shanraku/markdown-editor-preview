# Security Policy

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the maintainer through the GitHub profile.

## Security principles

- Markdown is rendered as escaped text; raw HTML is not intentionally supported.
- Links are limited to HTTP and HTTPS.
- Content is processed in the browser and is not uploaded by this application.
- Do not commit passwords, API keys, tokens, or personal data.
