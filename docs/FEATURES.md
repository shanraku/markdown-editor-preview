# Features and scope

## Included in this version

- Live preview while typing
- Headings, paragraphs, lists, blockquotes, horizontal rules
- Bold, italic, inline code, fenced code blocks
- Safe HTTP/HTTPS links
- Word count
- Copy Markdown and download a .md file
- Dark and light themes
- Responsive layout and reduced-motion support

## Privacy

The editor does not send document content to a server. It does not require an account, API key, or backend.

## Current limitations

This is a lightweight Markdown subset, not a complete CommonMark implementation. Tables, images, nested lists, and advanced extensions are not currently supported. Raw HTML is displayed as text rather than executed.
