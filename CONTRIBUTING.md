# Contributing

Thanks for considering a contribution!

1. Open an issue to discuss significant changes.
2. Fork the repository and create a focused branch.
3. Keep changes small, accessible, responsive, and dependency-light.
4. Never add secrets, tracking scripts, or unnecessary data collection.
5. Describe what changed and how you checked it in your pull request.

By contributing, you agree that your contributions are provided under the repository's MIT License.
